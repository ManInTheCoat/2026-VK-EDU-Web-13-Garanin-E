# Проект "Вопросы и Ответы"

Это репозиторий для учебного проекта-сервиса "Вопросы и Ответы".

## Как открыть проект

Для запуска проекта убедитесь, что на вашем компьютере установлен **Python** и фреймворк **Django**. Чтобы посмотреть верстку:
1. **Склонируйте репозиторий:**
  ```bash
  git clone https://github.com/ManInTheCoat/2026-VK-EDU-Web-13-Garanin-E.git
  ```
2. **Перейдите в папку проекта:**
  ```bash
  cd 2026-VK-EDU-Web-13-Garanin-E
  ```
3. **Запустите локальный сервер:**
  ```bash
  python manage.py runserver
  ```
4. **Откройте проект в браузере:** Перейдите по адресу http://127.0.0.1:8000/

## Список сверстанных страниц

Все страницы находятся в директории `public/`:
* `index.html` — Главная страница (листинг вопросов)
* `question.html` — Страница просмотра конкретного вопроса и ответов к нему
* `ask.html` — Страница создания нового вопроса
* `login.html` — Страница авторизации пользователя
* `signup.html` — Страница регистрации нового пользователя
* `profile.html` — Страница настройки профиля
